# MCT-1

### Dependencies / Prerequisites

Python (version 3.13+)

(thats about it)

### What does it do / what's it for?

In the rare case you want to translate Morse code offline (and you dont have a book to translate it manually or you just have it out for GUIs and the internet). This is who this script was designed for, to simply translate English > Morse code, and vise versa.

(also because i was bored)

### Installation

- 1) Install python 3 if you haven't already done so, here's where you can find the correct installation. (side note: add python to path) Here is where you can install python: [Click here for python installtion](https://www.python.org/)

- 2) Install the [morse_translator.py](https://github.com/tqe0/MCT-1/blob/main/morse_translator.py) script and run it on your device of choice that is able to run python.

### Usage

When loading the scripts you should see two options presented infront of you. ``option 1 english > morse`` and ``option 2 morse > english``

Option 1 is simply used by pressing 1 and then enter.

Option 2 is then again simply used by pressing 2 and then enter.

Option 1 you can place any valid **English** sentence and then pressing enter again will return a morse code version of it back to you.

Option 1 you can place any valid **Morse Code** sentence and then pressing enter again will return a English language version of it back to you.
